# Part A: Customer Segmentation Using K-Means

## 🏪 Business Problem

An online retailer wants to understand different types of customers.

The available information includes:

* **Monthly Spending**
* **App Visits**

K-Means Clustering is used to divide customers into **3 groups (K = 3)**.

---

## 📊 Dataset

The practical creates a small customer dataset containing eight customers:

| Customer | Monthly Spending | App Visits |
| -------- | ---------------: | ---------: |
| A        |             9000 |         20 |
| B        |             8500 |         18 |
| C        |             1200 |          3 |
| D        |             1500 |          4 |
| E        |             5000 |         10 |
| F        |             5500 |         12 |
| G        |             8800 |         19 |
| H        |             1800 |          5 |

The customer name is used only as an identifier. The clustering features are **Monthly Spending** and **App Visits**.

---

## 🔧 Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Google Colab

The notebook uses Pandas for the dataset, `KMeans` for clustering, and Matplotlib for visualization.

---

## 🤖 K-Means Clustering

The model is configured to create:

**K = 3 clusters**

```python
model = KMeans(n_clusters=3, random_state=42, n_init=10)
df["Cluster"] = model.fit_predict(X)
```

The resulting `Cluster` column assigns each customer to one of the three groups. The cluster numbers themselves do **not** represent good, average, or bad customers; they are simply labels generated by the model.

# Part B: Introduction to Reinforcement Learning

## 🚚 Business Scenario

A delivery company has two possible routes:

* Route A
* Route B

The objective is to understand how a system can learn from the results of choosing different routes.

In Reinforcement Learning, the basic process is:

**Taking an Action → Receiving a Reward → Learning from the Result**

---

## 🛣️ Route Rewards

The practical uses the following example rewards:

| Route   | Rewards        |
| ------- | -------------- |
| Route A | 5, 4, 6, 5, 4  |
| Route B | 8, 9, 7, 10, 8 |

The average reward is calculated for each route to demonstrate how reward feedback can influence future decisions.

---

## 🧩 Reinforcement Learning Components

| Component       | Example                                |
| --------------- | -------------------------------------- |
| **Agent**       | Delivery decision system               |
| **Environment** | Roads and traffic                      |
| **Action**      | Choose Route A or Route B              |
| **Reward**      | Feedback based on delivery performance |

This simple example demonstrates the basic relationship between an action and the reward received from that action.

---

## 🔍 Exploration vs Exploitation

### Exploration

Trying a new or less-used option.

**Example:**
Trying Route A even if Route B usually performs better.

### Exploitation

Using an option that is already known to perform well.

**Example:**
Choosing Route B because it has previously produced higher rewards.

The notebook demonstrates both concepts using simple Python examples.

---

# 📚 Machine Learning Comparison

| Machine Learning Type      | Main Idea                      | Business Example          |
| -------------------------- | ------------------------------ | ------------------------- |
| **Supervised Learning**    | Learn from known answers       | Customer churn prediction |
| **Unsupervised Learning**  | Discover hidden patterns       | Customer segmentation     |
| **Reinforcement Learning** | Learn from actions and rewards | Route optimization        |
